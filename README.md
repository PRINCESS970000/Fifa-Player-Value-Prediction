#  FIFA Player Data Analysis & Machine Learning Prediction

A comprehensive data analysis and machine learning project built to explore FIFA player datasets, analyze player statistics, age distribution, and overall ratings, and implement regression models to predict player market values.

---

##  Tools & Technologies Used
* **Programming Language:** Python 
* **Environment & IDE:** VS Code, Jupyter Notebooks
* **Data Manipulation & Analysis:** 
  * `Pandas` (Data cleaning, aggregation, and filtering)
  * `NumPy` (Numerical operations)
* **Data Visualization:** 
  * `Matplotlib` & `Seaborn` (Visualizing distributions, ratings, and statistical correlations)
* **Machine Learning & Modeling:** 
  * `Scikit-Learn` (Linear Regression, Model training, Train-Test Split, and Evaluation metrics like $R^2$ and RMSE)
* **Version Control:** Git & GitHub

---

##  Dataset Features
The dataset contains professional player records including:
* **Name & Position:** Player's name and tactical position (e.g., LW, GK, CB).
* **Age & Country:** Player demographics.
* **Overall Rating & Future Potential:** Current skill level and projected growth.
* **Team:** Associated club or national team.
* **Value Per M$:** Market value estimation.
* **Total_Stats Score:** Aggregated performance and attribute score.

---

##  Project Workflow
1. **Data Preprocessing & Cleaning:** Loading the `Fifa.csv` dataset, handling columns, checking data types, and handling missing values.
2. **Exploratory Data Analysis (EDA):** Generating statistical summaries and visualizing player attributes and rating distributions.
3. **Machine Learning Pipeline:** Building a predictive regression model using player attributes (Age, Overall Rating, Potential, Total Stats) to estimate player market values.
4. **Model Evaluation:** Assessing model performance using Mean Squared Error (MSE) and R-squared ($R^2$) scores.
